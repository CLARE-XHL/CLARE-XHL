# 🙋 Hello, World!

> *"Here's to the crazy ones. The misfits. The rebels. The troublemakers."*

欢迎来到 CLARE 的主页。我是一个 **14岁的独立开发者**，也是 **[CrCLARE 工作室](https://crclare.top)** 的创始人。

> **🎯 我的座右铭**：Go for it.
> **🏔️ 工作室口号**：奔赴顶峰，保持热爱（Here We Go）

我做游戏，也拆游戏。我写代码，也写文案。在现实世界里是个普通学生，但在赛博世界里，我用手搓的 C++ 装甲保护别人的创意。

**🚀 我正在做的：**
- 🛡️ **[Chronos Seal](https://github.com/CrCLARE/Chronos-Seal)** —— 给 RPG Maker MV/MZ 的运行时完整性保护方案。C++ 原生底层、零知识密钥派生、CSDP 增量补丁。
- 🎮 **Going Future（征途）** —— 一款属于我自己的独立游戏，正在构建中。
- 📝 **《宇宙乡·纪》** —— 原创世界观与小说，探索“嵌入式制度的缝隙”。

**🧗 我折腾过的硬核玩意儿：**
黑苹果 OpenCore · 3DS 破解 · NS 软破 · 云端 CI/CD 地狱 · N-API 跨版本编译

折腾教会我两件事：本地没有绝对安全；再难的玩意儿，花时间总能啃下来。
所以 Chronos Seal 不追求“绝对破不了”，只追求**“让破解成本远超游戏售价”**。
